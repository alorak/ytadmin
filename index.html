BAĞLANTI YÖNTEMİ 1

Google OAuth 2.0 ile bağlan

Önerilen yöntemdir. Google Cloud Console üzerinde YouTube Data API v3 ve YouTube Analytics API etkinleştirilmiş bir projeden Web application türünde OAuth Client ID oluşturun. Web uygulamanızın tam kaynağını Authorized JavaScript origins listesine ekleyin. OAuth izin ekranındaki test kullanıcılarını da yapılandırın.

İzinler: youtube.readonly ve yt-analytics.readonly. Client ID bu tarayıcıda saklanabilir; OAuth erişim token'ı saklanmaz. Google oturum açma kütüphanesi ancak bu düğmeye basıldığında yüklenir.
BAĞLANTI YÖNTEMİ 2

Geçici access token kullan

Test için Google OAuth 2.0 tarafından üretilmiş, gerekli kapsamları içeren erişim token'ını yapıştırabilirsiniz. YouTube Studio çerezi, oturum bilgisi veya API anahtarı geçerli değildir. Access token yalnızca sekmenin belleğinde tutulur ve yeniden yüklemede silinir.

Bağlantıyı kesmek yerel token'ı temizler; Google hesabınızda daha önce verdiğiniz OAuth iznini otomatik iptal etmez. Google Hesabı → Üçüncü taraf bağlantıları sayfasından izni kaldırabilirsiniz.

Kurulum ve güvenlik

Uygulama tek bir statik HTML dosyasıdır. Kendi sunucusu ve veritabanı yoktur; Google API istekleri doğrudan tarayıcınızdan yapılır. OAuth için uygulamayı HTTPS (ör. GitHub Pages) veya http://localhost üzerinden açın; file:// kaynakları OAuth için uygun değildir.

İlk açılışta otomatik bağlantı, yetkilendirme veya API isteği yapılmaz. Google'ın raporları gecikmeli güncellenebilir. Video listesindeki değerler yalnızca hesabınızın erişebildiği kanal ve videolarla sınırlıdır.
